Sobre este proyecto

Esta es una prueba de creación de páginas web usando GitHub Pages. Puedo añadir un diseño con CSS, lo que permite separar el contenido en tarjetas blancas sobre un fondo gris, haciéndolo mucho más agradable a la vista.

Aquí se puede agregar tantos párrafos como se necesiten para contar una historia, explicar un tutorial o presentar tu portafolio.
